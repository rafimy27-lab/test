Hubungkan ke Supabase

Website statis ini sudah siap untuk GitHub Pages. Isi supabase-config.js dengan Project URL dan publishable key dari Supabase, lalu unggah ulang ke GitHub.

  1. Buat project Supabase gratis.
  2. Jalankan supabase/schema.sql di SQL Editor.
  3. Isi konfigurasi frontend menggunakan publishable key, bukan secret/service_role.
