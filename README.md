3. **5 Asisten Deputi Support**:

5. **Cetak Lembar Disposisi Official**: Format standar Lembar Disposisi Deputi (Siap Cetak PDF/Paper A4).

## 🚀 Cara Upload ke Repositori GitHub & Aktifkan GitHub Pages

### Langkah 1: Buat Repositori Baru di GitHub
1. Buka [GitHub.com](https://github.com) dan buat repositori baru (misal: `esurat-deputi-infrastruktur`).
2. Atur visibilitas ke **Public** (atau Private jika menggunakan akun GitHub Enterprise).
3. Klik **Create repository**.

### Langkah 2: Upload Berkas
1. Di halaman repositori baru, klik tombol **uploading an existing file**.
2. Ekstrak berkas `esurat_kemenko_ipk_template.zip`.
3. Seret (Drag & Drop) seluruh berkas hasil ekstrak (`index.html`, `README.md`, `.nojekyll`) ke kolom upload GitHub.
4. Klik **Commit changes**.

### Langkah 3: Aktifkan GitHub Pages
1. Pergi ke tab **Settings** repositori Anda di GitHub.
2. Pada menu bilah kiri, klik **Pages**.
3. Di bawah bagian **Build and deployment** -> **Source**, pilih **Deploy from a branch**.
4. Pilih branch `main` (atau `master`) dan folder `/ (root)`.
5. Klik **Save**.
6. Dalam 1-2 menit, URL website Anda siap diakses melalui:
   `https://<username-anda>.github.io/<nama-repositori>/`
